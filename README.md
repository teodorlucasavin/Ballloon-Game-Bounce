Name: Ballloon Game Bounce

What it's about: The game features a balloon that flies through the sky. You need to protect it from the falling cubes. The longer you manage not to pop it, the higher your score is.

Controls: arrow keys (to make the circle shield move and bounce/push away the cubes.)
